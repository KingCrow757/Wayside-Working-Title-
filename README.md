# Wayside (working title)

The repository contains the canonical design Blueprint, the Production Edition audit, and a playable browser prototype of the first road-stewardship loop.

## Play the prototype locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/prototype/` in a modern browser. See [prototype/README.md](prototype/README.md) for controls, scope, and validation limits.
